## 🚀 GitHub Pages 배포 방법

1. GitHub에서 새 저장소(repository) 만들기
2. 이 폴더의 파일을 모두 업로드
3. 저장소 Settings → Pages → Source: main branch → Save
4. 잠시 후 `https://[아이디].github.io/[저장소이름]` 주소로 접속!

---

## ✏️ 수정이 필요할 때

**학교/반 이름 변경**: `index.html` 하단 footer 부분에서 수정  
**새 장소 추가**: `index.html` 내 `DATA` 객체에 새 항목 추가  
**이미지 교체**: 같은 파일명으로 덮어쓰기
